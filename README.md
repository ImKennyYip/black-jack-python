# [Black Jack (Pygame)](https://youtu.be/oyoRdXHWZiE)

- Coding Tutorial: [https://youtu.be/aBDMheayWzM](https://youtu.be/oyoRdXHWZiE)

How to code a black jack game in Python with Pygame for beginners! Learn how to create a game of black jack in Python using the pygame library.

In this tutorial, you will learn how to make the card game, black jack! You will learn how to create a deck, shuffle it, and deal cards to the dealer and the player. You will also learn to hit (draw cards) and stay (submit your hand) and compare the results to see who wins the round. After learning how to set up the game logic, you will learn how to create a graphical user interface (GUI) to display the player cards and listen for key presses to update the screen when you select hit, stay, or restart game.
